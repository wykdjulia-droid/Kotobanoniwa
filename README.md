# ことばの庭 Kotoba Garden

A cozy pixel-art Japanese-learning game: grow crops by answering N4 vocabulary, write kanji to keep the cottage tidy, and merge harvests into dishes for market customers by building N4 grammar sentences.

Play: https://wykdjulia-droid.github.io/Kotobanoniwa/

Stroke order data: [KanjiVG](https://kanjivg.tagaini.net) (CC BY-SA 3.0).
